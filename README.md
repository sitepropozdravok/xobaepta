# Поздравление для Тани

Статический сайт для GitHub Pages. Откройте `index.html` локально или загрузите содержимое этой папки в корень репозитория.

Чтобы опубликовать сайт: в репозитории откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`, затем сохраните.

Звуковые эффекты генерируются встроенным Web Audio только после нажатия на переключатель звука. Фотографии и сайт не требуют сервера; шрифты загружаются из Google Fonts с запасными системными шрифтами при отсутствии сети.
